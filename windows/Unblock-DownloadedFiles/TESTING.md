# ブロック解除スクリプトのテスト

このドキュメントでは、`Test-Unblock-DownloadedFiles.ps1` の実行方法とテスト内容を説明します。

## 実行方法

このフォルダーをカレントディレクトリにして、Windows PowerShell 5.1 で次のコマンドを実行します。

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File ".\Test-Unblock-DownloadedFiles.ps1"
```

PowerShell の実行ポリシーは変更せず、この実行プロセスに限って `-ExecutionPolicy Bypass` を指定します。

## テスト内容

テストスクリプトは、次の項目を自動で確認します。

1. 対象スクリプトのPowerShell構文を解析できること
2. 個別ファイルの `Zone.Identifier` が解除され、成功ログが記録されること
3. フォルダー直下とサブフォルダー内のファイルが再帰的に処理されること
4. ファイルとその親フォルダーを重複して指定しても、ファイルが一度だけ処理されること
5. 存在しないパスを指定するとエラーがログに記録され、失敗の終了コードが返ること
6. 対象を指定しないとエラーがログに記録され、失敗の終了コードが返ること
7. `Logs` フォルダーに日時入りのログファイルが作成されること

テストでは一時フォルダーにテスト用ファイルを作り、`Zone.Identifier` を付けてから解除を確認します。実際のダウンロードファイルや利用者のファイルは変更しません。テスト用スクリプトとログも一時フォルダー内に作成され、通常終了時に削除されます。

## テスト結果

実行結果は、このドキュメントと同じフォルダーにある `TestResults.txt` に保存されます。実行のたびに上書きされ、各テストの `PASS` / `FAIL`、実行日時、PowerShellのバージョンが記録されます。

- 終了コード `0`: すべて成功
- 終了コード `1`: 1件以上失敗、またはテスト実行中にエラー

## 実行環境

- Windows PowerShell 5.1
- `Zone.Identifier` の代替データストリームを扱えるファイルシステム
