# ダウンロードファイルのブロック解除

Windowsでダウンロードしたファイルに付与されるブロック情報を解除する、CUIのPowerShellスクリプトです。

## ファイル構成

- `Unblock-DownloadedFiles.ps1`: ファイルやフォルダー内のファイルを処理するスクリプト
- `Unblock-DownloadedFiles.bat`: PowerShellスクリプトを起動するバッチファイル
- `Logs\`: 実行ログの保存先。実行時にフォルダーがなければ作成されます。

## 使い方

### ドラッグ＆ドロップ

ブロックを解除したいファイルまたはフォルダーを `Unblock-DownloadedFiles.bat` にドラッグ＆ドロップします。複数のファイルやフォルダーを同時に指定できます。

処理の進行状況はコンソールに表示されます。バッチファイルは処理結果を表示した後、キー入力を待ってから終了します。

### コマンドラインから実行

PowerShellから、対象のパスを指定して実行できます。

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File ".\Unblock-DownloadedFiles.ps1" "C:\Downloads\sample.zip"
```

フォルダーを指定する場合は、そのフォルダー内のファイルとサブフォルダー内のファイルが再帰的に処理されます。

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File ".\Unblock-DownloadedFiles.ps1" "C:\Downloads"
```

`-ExecutionPolicy Bypass` は起動したPowerShellプロセスにだけ適用され、システムやユーザーの実行ポリシー設定は変更しません。

## 処理内容

1. 指定された各パスが存在するか確認します。
2. ファイルはそのまま処理対象にします。フォルダーは配下を再帰検索し、隠しファイルも含めてファイルを収集します。
3. 同じファイルが複数回指定されても、一度だけ処理します。
4. 各ファイルに `Unblock-File` を実行します。ブロック情報がないファイルも対象に含まれます。
5. 開始・処理結果・集計をコンソールとログに出力します。
6. エラーが発生した場合は、処理を継続できる対象を処理したうえで、エラー終了コードを返します。

## ログ

ログはスクリプトと同じ場所にある `Logs` フォルダーへ保存されます。ファイル名には実行日時が含まれます。

```text
Logs\UnblockFiles_yyyyMMdd_HHmmss_fff.log
```

保存先を変更する場合は、`Unblock-DownloadedFiles.ps1` 冒頭の `$logDirectory` を編集してください。

## 終了コード

- `0`: エラーなしで処理終了
- `1`: 対象の指定・検索・ブロック解除のいずれかでエラーが発生

コマンドラインから実行した場合は、`$LASTEXITCODE` で終了コードを確認できます。

## 注意事項

- ブロック解除により、ファイルがインターネットから取得されたことを示す情報が削除され、Windowsの警告表示に影響する場合があります。信頼できるファイルだけを対象にしてください。
- フォルダーを指定すると、その配下のファイルをすべて処理します。サブフォルダーも対象になるため、指定するフォルダーを確認してください。
- ファイルやフォルダーへのアクセス権がない場合などは、ログにエラーが記録されます。
- テストスクリプトの実行方法については、[TESTING.md](./TESTING.md) を参照してください。
