### 見出しレベル3（H3）

- 箇条書きリスト（unordered）
- 2つ目の項目
  - ネストされたリストです。
  - ネストされたリストの **太字** です。
- 3つ目の項目
  - ネストされたリストの *斜体* です。
  - ネストされたリストの ***太字＋斜体*** です。
  - ネストされたリストの ~~打ち消し線~~ です。

1. 番号付きリスト（ordered）
1. 2番目の項目
   1. ネストされたリストです。
   1. ネストされたリストの **太字** です。
1. 3番目の項目
   1. ネストされたリストの *斜体* です。
   1. ネストされたリストの ***太字＋斜体*** です。
   1. ネストされたリストの ~~打ち消し線~~ です。

###### 見出しレベル6（H6）

リンクの例：

- 自動リンク
  <https://example.com>

- 通常のリンク
  <https://example.com>

- 画像リンク
  image.png

---

HTML を含む例（標準 Markdown 対応）：

```html
<div>
  <span style="color:red">これは HTML タグです</span>
</div>
```
